# Command Menu AP

A client-side Fabric mod for Minecraft that provides a streamlined command quick-access menu using a custom minimalist interface.

---

## Overview

Command Menu AP replaces vanilla screen layouts with a modern custom UI. It allows quick access to frequently used commands through category tabs, flexible icon rendering, and full in-game configuration.

### Features

* Full GUI management to add, update, and remove commands directly in-game.
* Automatic profile isolation based on server IP or singleplayer world name.
* Multi-source icon rendering: registry items, local PNG files, and external web URLs.
* Header text formatting supporting solid colors, gradients, and animated rainbow modes.
